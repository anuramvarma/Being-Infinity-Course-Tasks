# TicTacToe – Java Console Game

A command-line based **Tic Tac Toe game** developed using **Java**,allowing two players to compete against each other in a turn-based manner.  
The game is interactive,user-friendly, and displays the board after every move.

---
## key Features
- 3 × 3 Tic Tac Toe board
- Two-player mode (Player X & Player O)
- Input validation (range, format, occupied cell or not)
- Automatic winner detection
- Draw detection
- Match summary after game completion
- Option to replay the game
---

## How to Run the Game in your System.

1. Save the file as `TicTacToe.java`
2. Open terminal / command prompt
3. Compile the program:
   ```bash
   javac TicTacToe.java
   java TicTacToe
